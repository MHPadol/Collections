# Big O Notations in Java
## 📌 Description

This project demonstrates different Big O time complexity classes using Java methods and algorithms.

Each example shows how the amount of work changes as the input size increases.

## Complexities Covered

| Big O | Complexity | Example |
|---|---|---|
| O(1) | Constant | Array Access / Even Check |
| O(log n) | Logarithmic | Binary Search |
| O(n) | Linear | Find Maximum / Sum Array |
| O(n log n) | Linearithmic | Merge Sort |
| O(n²) | Quadratic | Bubble Sort / Duplicate Pairs |
| O(n³) | Cubic | Triple Nested Loops |
| O(2ⁿ) | Exponential | Recursive Fibonacci |
| O(n!) | Factorial | Permutations |

## Technologies Used

## Learning Objective
The goal of this project is to understand the basic Big O complexity classes and recognize how different algorithms perform as the amount of data increases.
